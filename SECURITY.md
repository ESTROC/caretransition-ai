# Security

CareTransition AI is a portfolio and engineering demonstration.

## Do not submit PHI
The public API is not designed to process protected health information (PHI). Use only synthetic or properly de-identified test data.

## Production deployment
A real deployment must add authentication and authorization, TLS, secrets management, audit logging, network controls, rate limiting, dependency scanning, vulnerability management, encrypted storage, access monitoring, and a formal privacy/security review.

## Reporting
For vulnerabilities in a deployed fork, report them privately to the repository owner rather than posting patient or security-sensitive information in a public issue.
